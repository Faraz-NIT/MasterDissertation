# Standalone dissertation appendices

`Full_Dissertation_Appendices.docx` contains Appendices A–I only, with 17 tables and 14 figures. It covers the clean M5/RetailNet study, the full LangGraph architecture comparison, and the separately labelled LangChain validation. The 3% scenario is explicitly hypothetical, not an observed result.

The manuscript, tables, source hashes and document validation receipt are preserved here. No new experiments or model calls were made to prepare this document.

Build from the repository root with `python scripts/dissertation_appendices/build.py`. Render the Word file to PDF with LibreOffice in this directory, then run `python scripts/dissertation_appendices/verify.py`. The internal PDF and review PNGs are excluded from Git. The final 32-page render and selected full-size pages were visually reviewed after automated verification; the Word file is the requested deliverable.
